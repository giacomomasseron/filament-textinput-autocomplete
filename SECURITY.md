# Security Policy

## Supported Versions

Security updates are provided for the latest released major version of
`giacomomasseron/filament-textinput-autocomplete`.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues,
discussions, or pull requests.

Instead, report them privately using one of the following channels:

- **GitHub Security Advisories** — use the
  ["Report a vulnerability"](https://github.com/giacomomasseron/filament-textinput-autocomplete/security/advisories/new)
  button on the repository's Security tab (preferred).
- **Email** — send details to **giacomom@gmail.com**.

Please include as much of the following as you can to help us triage quickly:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept.
- Affected version(s) and environment (PHP, Laravel, Filament).
- Any suggested remediation, if you have one.

## Response Process

- We will acknowledge your report within **5 business days**.
- We will investigate and keep you informed of the progress.
- Once a fix is ready, we will release a patched version and, where appropriate,
  publish a GitHub Security Advisory crediting the reporter (unless you prefer to
  remain anonymous).

Thank you for helping keep this project and its users safe.
